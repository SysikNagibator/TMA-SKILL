# i18n (RU/EN)

- Source of truth: `user.language_code` from validated initData (not browser locale). Default RU if `ru/uk/be/kk`, else EN.
- String tables `locales/{ru,en}.json`, keyed (`cart.pay_button`: "Оплатить {sum}"), no concatenated sentences.
- RU plurals: one/few/many (`1 товар, 3 товара, 5 товаров`) — use `Intl.PluralRules('ru')`. Dates: `Intl.DateTimeFormat('ru-RU', {...})`, never `MM/DD/YYYY` for RU. Currency: `Intl.NumberFormat('ru-RU', {style:'currency', currency:'RUB'})` → "450 ₽" (narrow nbsp, symbol after).
- RTL: not needed for RU/EN; keep logical CSS properties anyway (`margin-inline-start`).
- Bot chat messages may use 1–2 emojis; Mini App UI strings use none (icons instead).
- Toggle in Settings only if the audience is truly mixed; otherwise follow Telegram language silently.
