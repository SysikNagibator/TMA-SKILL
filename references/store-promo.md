# Store & promo (BotFather)

- Main Mini App (`/newapp` or promote existing): profile gets Launch button + Apps-tab presence + `t.me/bot?startapp` links. Upload: icon, loading-screen colors (light+dark), 3–5 screenshots, demo video, EN+RU descriptions.
- Stars-accepting quality apps may be featured in the Mini App Store — invest in previews.
- Short name + description for search; `startapp` campaigns per channel (`?startapp=blog_may`) to attribute installs.
- Homescreen shortcut (`addToHomeScreen`) + emoji-status/gift hooks (8.0+) only where they add virality, not by default.
- Never ship BotFather with tunnel URL as final — tunnels are dev-only; prod = stable domain (see deploy-prod.md).
