# Microcopy (RU/EN, human not robotic)

Voice: short, warm, specific. Verb-first buttons: "Оплатить 450 ₽" / "Pay 450 ₽", "Забронировать" / "Book", not "OK/Submit/Далее".
Empty: "Пока пусто — билеты появятся за неделю до матча" + [Notify me]. Errors: what + fix ("Нет соединения — проверь интернет" + [Retry]). Success: fact + next ("Оплачено. Чек в чате с ботом.").
Bot chat messages: 1 emoji max, plain language; Mini App UI: zero UI emojis. Dates/prices via Intl (see i18n.md). No lorem, no EN leftovers in RU build — grep `TODO|Lorem|Submit` before ship.
