# Accessibility in mobile WebView

- Every input has a visible `<label>`; icon-buttons have `aria-label`. Images informative → `alt`; decorative → `alt=""`.
- Contrast AA on BOTH Telegram themes (text/bg ≥ 4.5). Test with system Bold Text / larger fonts — layout must not break at 135% text size.
- Touch targets ≥ 44px; focus-visible ring uses Refero accent; focus trap in modals/popups.
- Screen readers (TalkBack/VoiceOver over WebView): semantic buttons/headings, `aria-live="polite"` for cart totals/score changes, no div-soup clicks.
- Don't hijack gestures: keep Telegram vertical swipes unless the screen truly needs them (see motion.md). No auto-playing video with sound.
- Errors announced as text near the field + BottomButton stays disabled with reason in hint color.
